## 🔄 Development Workflow

This project uses Git and GitHub for version control.

The development workflow is:

```text
Make changes
     ↓
git status
     ↓
git add .
     ↓
git commit
     ↓
git push
     ↓
GitHub
     ↓
Netlify
     ↓
Automatic deployment
```

Once the repository is connected to Netlify, pushing changes to the production branch automatically triggers a new deployment.
